# my_9_project_last_the_final_task
Итоговое домашнее задание на проверку знаний по работе с API внешних сервисов, обработка и анализ логов, выявление потенциальных угроз, имитирование мер реагирования, формирование отчетности с визуализацией

## Программа анализирует два источника данных:
- VirusTotal API для проверки подозрительных файлов
- PCAP файл с сетевым трафиком (логи Suricata)

## Функциональность
- Загружает и анализирует pcap файл (подсчет пакетов, IP, портов)
- Проверяет файлы через VirusTotal API (с кешированием)
- Обнаруживает угрозы: SYN сканирование, опасные порты
- Имитирует реагирование (блокировка IP/портов)
- Создает отчеты в JSON и CSV
- Генерирует графики в PNG
